# Offers Templates
منصة عربية RTL لاستيراد بيانات المطاعم من لوحة توصيل وَن وتصميم عروض تسويقية قابلة للتخصيص.

## التقنية
- Next.js App Router + TypeScript
- Vercel Functions
- Neon PostgreSQL
- Canvas بدقة تصدير 615×520 PNG

## التشغيل
1. `npm install`
2. أضف `DATABASE_URL` و`IMPORT_API_TOKEN` في إعدادات Vercel.
3. `npm run dev`

## الاستيراد
من صفحة سحب بيانات المطاعم اسحب Bookmarklet إلى شريط الإشارات المرجعية. افتح قائمة المتاجر في توصيل وَن وشغله. يكتشف روابط الفروع الموجودة في قائمة الفرع، ينتقل إلى كل فرع متاح في جلسة المتصفح نفسها، ثم يتبع ترقيم صفحات `/admin/market` ويقرأ الأعمدة: الرقم، الصورة، الاسم، العنوان، التصنيف، النوع، الحالة. يرسل الدفعات إلى API مع مفتاح استيراد.

الأداة لا تقرأ كلمات المرور أو ملفات تعريف الارتباط أو تخزنها. وهي لا تتجاوز صلاحيات حساب توصيل وَن؛ الفروع التي لا تظهر في قائمة الحساب لا يتم استيرادها. يجب أن يطابق نطاق النظام `tawseel.app` وبنية الصفحة الحالية.

## استوديو التصميم
سبعة قوالب SVG قابلة للمعاينة، اختيار فرع ومطعم، استيراد الشعار، إضافة صورة، تعديل النصوص والألوان والأحجام، سحب العناصر على اللوحة، حفظ إعدادات التصميم، وتصدير PNG.

## الأمان
- مسار الاستيراد يتحقق من أصل الطلب ومفتاح `IMPORT_API_TOKEN` بمقارنة ثابتة الزمن.
- شعار المطعم يمر عبر proxy مقيد بمضيف `cdn.tawseel.app` لتجنب تعارض CORS في Canvas.
- مفاتيح قاعدة البيانات والاستيراد تحفظ في Environment Variables المشفرة في Vercel ولا تضاف إلى Git.
